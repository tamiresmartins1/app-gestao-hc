✅ SEU CÓDIGO JÁ ESTÁ PRONTO NO GIT!

Agora só precisa fazer 3 coisas:

═══════════════════════════════════════════════════════════════════════════════
PASSO 1: CRIAR CONTA NO GITHUB (se não tiver)
═══════════════════════════════════════════════════════════════════════════════

1. Abra seu navegador
2. Acesse: https://github.com/signup
3. Preencha:
   - Username (qualquer nome, ex: seu nome)
   - Email (seu email)
   - Senha (uma senha segura)
4. Clique: Create account
5. Valide o email (vai receber email do GitHub)

⏱️ Tempo: 2 minutos

═══════════════════════════════════════════════════════════════════════════════
PASSO 2: CRIAR REPOSITÓRIO NO GITHUB
═══════════════════════════════════════════════════════════════════════════════

1. Após criar conta, acesse: https://github.com/new
2. Preencha:
   - Repository name: app-gestao-hc
   - Description: Sistema de gestão de tarefas
3. Escolha: Public
4. Clique: Create repository

Você verá uma página com instruções de push.
COPIE a URL que aparece (será algo como: https://github.com/SEU_USERNAME/app-gestao-hc.git)

⏱️ Tempo: 1 minuto

═══════════════════════════════════════════════════════════════════════════════
PASSO 3: FAZER PUSH DO CÓDIGO (via PowerShell)
═══════════════════════════════════════════════════════════════════════════════

1. Abra o PowerShell
2. Cole e execute este comando (substitua a URL):

git remote add origin https://github.com/SEU_USERNAME/app-gestao-hc.git
git branch -M main
git push -u origin main

SUBSTITUA "SEU_USERNAME" pelo seu username do GitHub!

3. Quando pedir username/token:
   - Username: seu username do GitHub
   - Senha/Token: crie um token em https://github.com/settings/tokens
     (gere novo token com permissão "repo")

⏱️ Tempo: 1 minuto

═══════════════════════════════════════════════════════════════════════════════
PASSO 4: DEPLOY NO NETLIFY (automático!)
═══════════════════════════════════════════════════════════════════════════════

1. Abra o Netlify que você já tem aberto: https://app.netlify.com
2. Se não estiver logado, clique: Log in > GitHub
3. Após logar, clique: Add new site > Import an existing project
4. Selecione: GitHub
5. Procure: app-gestao-hc
6. Configure:
   - Base directory: frontend
   - Build command: npm run build
   - Publish directory: frontend/dist
7. Clique: Deploy site

AGUARDE 2-3 MINUTOS!

Você verá uma URL como: https://seu-site.netlify.app

⏱️ Tempo: 5 minutos

═══════════════════════════════════════════════════════════════════════════════
PASSO 5: CONFIGURAR BACKEND (Render)
═══════════════════════════════════════════════════════════════════════════════

1. Abra: https://render.com
2. Clique: Sign up > GitHub
3. Authorize
4. Clique: New + > Web Service
5. Selecione: app-gestao-hc
6. Preencha:
   - Name: app-gestao-hc-backend
   - Environment: Node
   - Build Command: cd backend && npm install
   - Start Command: node backend/server.js
   - Plan: Free
7. Clique: Create Web Service

COPIE a URL que aparecer! (ex: https://app-gestao-hc-backend.onrender.com)

AGUARDE 3-5 MINUTOS!

⏱️ Tempo: 5 minutos

═══════════════════════════════════════════════════════════════════════════════
PASSO 6: CONECTAR BACKEND AO FRONTEND (últime passo!)
═══════════════════════════════════════════════════════════════════════════════

1. Volte ao Netlify
2. Clique: Site settings
3. Clique: Environment (menu esquerdo)
4. Clique: Add environment variable
5. Campo: VITE_API_URL
   Valor: (copie a URL do backend que você anotou)
   Exemplo: https://app-gestao-hc-backend.onrender.com
6. Clique: Save
7. Volte para: Deploys
8. Clique: Trigger deploy > Deploy site

AGUARDE 1-2 MINUTOS!

⏱️ Tempo: 2 minutos

═══════════════════════════════════════════════════════════════════════════════
✅ PRONTO! SEU APP ESTÁ NO AR!
═══════════════════════════════════════════════════════════════════════════════

Tempo total: ~20 minutos

URLs finais:
  Frontend: https://seu-site.netlify.app (copie essa URL!)
  Backend: https://app-gestao-hc-backend.onrender.com
  Código: https://github.com/seu-username/app-gestao-hc

Teste:
  1. Acesse a URL do Frontend
  2. Clique em "+ Novo Membro"
  3. Crie um membro
  4. Vá para "Minhas Tarefas" e crie uma tarefa
  5. Pronto! Tudo funcionando! 🎉

═══════════════════════════════════════════════════════════════════════════════
💡 DICAS
═══════════════════════════════════════════════════════════════════════════════

1. Se der erro no Netlify, verifique se a URL do backend está correta
2. Se der erro no Render, aguarde um pouco (pode demorar)
3. Se der erro no git push, use Personal Access Token (veja DEPLOY.md)

═══════════════════════════════════════════════════════════════════════════════

Bom deploy! 🚀
