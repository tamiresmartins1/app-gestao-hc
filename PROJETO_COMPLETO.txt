DATABASE
  • SQLite3 (arquivo local)
  • 5 tabelas (members, tasks, messages, processes, process_tasks)
  • Pronto para migrar para PostgreSQL em produção

COMO COMEÇAR (3 PASSOS)
═══════════════════════════════════════════════════════════════════════════════

PASSO 1: Instalar Node.js
  → Acesse: https://nodejs.org/
  → Baixe a versão LTS
  → Execute o instalador
  → Reinicie o computador

PASSO 2: Setup do APP (execute 1x)
  → Opção A: Clique 2x em "setup.bat" (automático)
  → Opção B: Siga o guia em SETUP.md (manual)
  → Aguarde instalar dependências (pode levar 5 minutos)

PASSO 3: Rodar o APP
  → Clique 2x em "run.bat" (abre backend e frontend)
  → OU abra 2 terminais e execute:
     - Terminal 1: cd backend && npm run dev
     - Terminal 2: cd frontend && npm run dev
  → Acesse: http://localhost:5173

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problema: "npm: command not found"
Solução: Instale Node.js de https://nodejs.org/

Problema: "Port 5000 already in use"
Solução: Mude a porta em backend/.env

Problema: "Cannot find module"
Solução: Delete pasta node_modules e execute npm install novamente

Problema: Banco de dados corrompido
Solução: Delete backend/app_gestao.db e reinicie
