OPÇÃO 1: DEPLOY AUTOMÁTICO (RECOMENDADO) ⭐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Abra Netlify: https://app.netlify.com
2. Clique: "Add new site"
3. Escolha: "Import an existing project"
4. Selecione: "GitHub"
5. Procure: "app-gestao-hc"
6. Preencha:
   - Base directory: frontend
   - Build command: npm run build
   - Publish directory: frontend/dist
7. Clique: "Deploy"
8. PRONTO! Seu site estará em: https://seu-site.netlify.app

Tempo: ~5 minutos

OPÇÃO 2: RODAR LOCALMENTE
━━━━━━━━━━━━━━━━━━━━━━━━━

1. Instale Node.js: https://nodejs.org/
2. Execute: setup.bat
3. Execute: run.bat
4. Acesse: http://localhost:5173

Tempo: ~10 minutos
